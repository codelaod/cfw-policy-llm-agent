# 原型 v0.2：交互与视觉设计约束

日期：2026-10-26。状态：需求复审用的离线中保真原型；不是正式前端或已批准的设计系统。

## 1. 问题与本轮目标

旧稿把起点建议、场景选择、调试事件、确认表单、证据和结果放在相近的视觉层级。审阅者很难快速回答“我在哪里、下一步做什么、这个结果凭什么成立”。本轮不是单纯换配色，而是重建信息层级。

本原型服务运维／安全人员完成一次有限范围的配置审计，不做营销站点。视觉锚点是**清晰的审计工作区和可追溯证据链**，不使用大幅营销插画、装饰渐变、虚构健康分或默认满屏风险卡片。

## 2. 设计令牌

| 角色 | 取值 | 用途 |
| --- | --- | --- |
| 画布 | `#F5F7FB` | 工作区背景 |
| 表面 | `#FFFFFF` | 导航、表格和编辑区 |
| 主文字 | `#17243A` | 页面标题、主要信息 |
| 主操作 | `#2459D3` | 创建、确认、下一步；不用于所有链接之外的装饰 |
| 证据／正常 | `#167356` | 已确认、只读状态；不把未运行检查标成通过 |
| 复核／未知 | `#915800` | 待确认与信息不足；语义同时使用文字而非只靠颜色 |

- 中文正文：优先系统中文无衬线字体；离线运行，不下载字体。标题 26/22/18px，正文 14/15px，辅助文字不小于 12px。
- 资源 ID、策略表达式和证据引用用等宽字体，不用于大面积说明文字。
- 基础间距 4/8/12/16/24/32px；表面边框轻量，避免每段文字都包成同样的卡片。
- 对齐以左对齐为主；数字、版本、状态采用稳定列宽；正文单段不过长。

## 3. 布局与交互

```text
┌───────────────┬─────────────────────────────────────────────┐
│ 产品 / 演示空间│ 当前位置                    离线评审 / 使用说明 │
│               ├─────────────────────────────────────────────┤
│ 审计工作台     │ 页面标题 + 一句目的              唯一主操作     │
│ 资产与业务     │ 状态 / 范围 / 数据时点（信息行，不是健康评分）   │
│ 审计任务       ├────────────────────────────┬────────────────┤
│ 发现与建议     │ 主要内容：表格、流程或报告    │ 下一步 / 证据   │
│ 报告与复审     │                            │ 按需展开       │
│               └────────────────────────────┴────────────────┤
│ 无云账号连接   │ 明确的人工数据、模拟执行和内存状态说明          │
└───────────────┴─────────────────────────────────────────────┘
```

- 五个业务视图不再挤成一排步骤按钮，左侧固定定位，页面内只呈现当前任务。
- 首屏为空态：明确提供“载入人工样例”，不预造审计完成或风险数字。
- 工作台给出资料状态和下一步；资产页分开事实、候选与确认；审计页先预览再执行模拟；发现页分开结论、证据和处理计划；报告页保留固定输入版本。
- 互联网入向、有限出向、NAT 边界分别选择，不混合计算。出向／NAT 已获需求确认，但仍是人工交互例子，不代表已有云接口或设计 G2 通过。
- 候选默认不写入授权来源；先预览、后确认；编辑会使旧预览失效。切换资产不能复用另一资产的预览。
- 审阅“加入本地待办／暂缓”不改写发现状态，也不代表整改完成。
- 旧任务冻结画像、边界、来源与情境；改资料不能偷偷改旧结果。进行中的任务不可被另一个新任务覆盖。
- 取消后保留已得到的模拟结果；模型失败和资料不完整展示局限及下一步。
- 复杂说明用 disclosure；正常流程不默认展示原始 JSON、源码式事件或大块调试日志。

## 4. 可访问性与小屏

语义化导航、标题、按钮与表单 label；可见焦点、跳过导航、`aria-current`、状态 live region；不只用颜色传递含义。窄屏改成顶部横向业务导航，双列按阅读顺序堆叠；表格只在自身容器横向滚动。无自动动画，尊重减少动态偏好。

## 5. 评审与实现边界

- 本轮采用外部设计 skill 的设计方法和界面检查清单，不照搬第三方网页或把 React 组件栈引入正式选型。
- 原型保持单个 HTML，原生 CSS／JavaScript，无远程图片、字体、SDK、模型或云调用。数据只在页面内存中。
- 连续会话持久化、新鲜度调度、真实凭据、真正 Agent 工具调用与规则计算仍未实现。
- 正式前端需要 G2 后独立构建，遵循经评审的设计令牌、页面行为与验收条款；不能把该原型直接当正式组件交付。
