# v0.4 对话工作区设计

日期：2026-10-29。面向运维与安全人员，主要任务是在有限范围内解释云防火墙配置风险、确认业务要求并形成可人工执行的建议。产品契约见 [PRD](../../requirements/product.md)，代表性会话见 [J01～J24](../../requirements/customer-journeys.json)。原型仅以人工资料模拟，不宣称正式产品实现。

## 设计选择

保留已有审计工具的轻色、绿色主操作方向。视觉记忆点放在“连续对话旁始终可定位的固定证据”，不引入营销图、健康分或满屏等权风险卡。开始时直接问目标，无需载入样例或先挑快照；名称、ID、地域、资源类型和有来源业务组在对话中逐步变成规范范围。

| 令牌 | 取值 | 作用 |
| --- | --- | --- |
| 画布 | `#F5F7F8` | 安静的对话背景 |
| 表面 | `#FFFFFF` | 计划、表单与证据阅读 |
| 文字 | `#182D39` | 高对比正文 |
| 次文字 | `#627580` | 来源、时点、限制 |
| 主操作 | `#087B63` | 确认与本地处理动作 |
| 待确认 | `#8B5B10` | 信息不足、部分结果；同时给文字标签 |

系统中文字体离线显示；正文 14px、辅助 11～12px，标题 19／27px。资源 ID 才使用等宽字体。图形仅为轻量本地线条与符号，无远程字体或媒体。4／8／12／16／24／32px 间距，浅边框表示真实业务分组，不把每段话都切成卡片。

```text
会话导航             连续对话（主工作区）                 辅助资料
新建／重开会话       用户目标、澄清与确认                  对象／结果／报告／历史
会话各自的对象       计划确认 → 自动执行反馈               固定范围、来源和时点
                     业务确认或结果追问                   证据、条件、影响与审阅
演示情境（折叠）     情境建议短语 + 输入框                 按需打开
```

初始构思审校时，去掉了五个大工作区作为必经步骤和手动 L0～L4 推进按钮。它们让内部实现承担了客户导航职责，也使对话退化成旁边的一次问答。新布局把计划／业务确认留在对话，把大量对象和可追溯细节放在辅助板；正常客户无需操作情境控制或看 JSON／API／HTTP 参数。

## 客户交互约束

- 一条审计意图允许澄清和修订；相同词语带不同地域／类型会得到不同候选。规范身份未明确时不能默认第一项。20 对象组和超过 51 对象的完整目录与会话并发数无关。
- 执行计划列明对象、边界、合格复用／必要刷新或强制重采、业务版本、模型模式和只读效果。改变对象、边界或集合使旧预览失效。
- 自动事实、候选和用户确认分开。角色、允许访问、必要访问独立预览与版本确认；拒绝候选不删除已有确认。空来源保持未知，默认不编造管理白名单。
- 入向、出向、NAT ACL 使用独立范围。出向不继承入向来源；网关策略集事实与缺资产关联分别展示。没有映射不阻止阅读网关 ACL，也不能证明特定资产路径。
- 计划接受后自动准备资料、封存、展示规则、补充解释并汇总。慢模型前规则已经可见；取消、额度耗尽或失败保留适用结果。没有虚假完成百分比。
- 同会话一个未结束任务，三个不同会话执行，第四个排队。状态查询、重复提交或恢复观察不创建另一个任务。观察投影只呈现已收到事件，断线不取消。
- 结果明确区分规则事实、业务推导、待确认、信息不足、不支持和模型候选。每项包含定位证据、成立条件和可能影响；结果不是整体安全或可达性证明。
- 旧任务封存对象、输入、业务版本与情境。待办／暂缓仅形成独立审阅记录；固定报告可打开和导出。改后复审另确认重采计划，改善、仍存在、新增与不可比较分别演示。
- 云写、越界、无关输入、外部内容注入和已识别敏感内容分别回应。正常“忽略刚才地域，改查北京”仍是合法目标修订。

## 实现与正式组件方向

`index.html` 提供语义页面；`styles.css` 管理令牌／布局；`engine.js` 是可独立检查的有限人工状态机；`app.js` 仅负责客户呈现、表单和自动计时推进。无网络、浏览器存储或真实规则算法，避免把页面外观误当后台能力。

沿用 Vue／Vite／Router、Nuxt UI v4／Tailwind 的既定正式方向：会话列表可映射按钮／导航，对话消息映射应用布局，计划与版本确认映射 Card／Modal／Form，证据与报告映射 Tabs／Accordion／Table。这里未安装或实例化这些组件，不能声称已验证其尺寸、行为或可访问性。

键盘焦点、跳转对话、label、dialog、状态文字与减少动态偏好均保留。窄屏会话变为顶部短导航，辅助板通过显式按钮展开；不让整个文档横向滚动。验证分为 88 个实际人工分支断言、范围／服务／来源不变量和真实 Chromium 表单／报告操作。重开历史与中断有可见人工效果，磁盘刷新／重启恢复仍为 2 项技术保证差异；不声称自由自然语言理解。实际浏览器检查和未覆盖边界见 [README](README.md)，不能以截图或有限状态回归替代完整业务验收。
