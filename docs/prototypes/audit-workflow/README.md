# 云防火墙审计交互原型 v0.3

原生HTML／CSS／JS、人工数据与固定模拟结果；用于已批准流程的交互参考，**不是正式Vue组件、规则引擎、Agent或真实SSE**。直接浏览器打开[index.html](index.html)，无依赖安装／服务／模型或云账号；CSP禁止网络，刷新清空内存。

## 1. 看什么

按[设计说明](DESIGN.md)映射Nuxt UI／Tailwind视觉方向，但未安装或运行这些组件。五个工作区保留事实／候选／确认、审计、证据、审阅、固定报告与复审预览，出向／NAT已在B2内，不做SNAT／DNAT转换审计。

1. 工作台载入人工样例，查看范围与资料缺口。
2. 资产与业务生成模拟候选，规范化预览后明确确认，或保留未知。
3. 审计选择一个边界并启动／推进／完成或取消模拟任务。
4. 发现与建议查看证据、条件、影响及本地处理计划。
5. 报告引用固定输入；准备复审只打开预览，不自动执行。
6. 连接情境模拟断线、补发／去重、轮询、显式取消和模型失败保留规则；没有真实网络恢复。

本原型仅演示单页单个活动任务，不验收正式3会话并发；无持久连续会话、真实上传／采集、LLM、规则计算、鉴权、完整出向表单或正式导出API。正式设计见[前端与事件](../../design/frontend-and-events.md)，需求见[PRD](../../requirements/product.md)。
