# 云防火墙审计交互原型 v0.2

日期：2026-10-26。**离线中保真交互评审，不是正式 Web 前端、规则引擎或 Agent。**

直接用浏览器打开 [index.html](index.html)，不需要安装依赖、启动服务、云账号或模型。无外部字体／图片／SDK，页面 CSP 禁止网络连接；全部为人工数据和固定模拟结果，仅在页面内存保存，刷新即清空。

## 建议按这条路径审阅

1. 工作台点击“载入人工样例”，看资料范围、资产确认状态与下一步。
2. 资产与业务：先看事实，再生成模拟候选；核实角色、服务与来源，预览后确认。也可保留未知。
3. 审计任务：选择一个边界，阅读资料缺口，再显式启动、推进规则阶段、模拟完成或取消。
4. 发现与建议：检查原始状态、判据、定位证据、条件与影响；加入本地待办或说明暂缓原因。
5. 报告与复审：查看固定输入；修改画像后，旧报告保持旧版本。“准备复审”只打开预览，不自动创建任务或采集。
6. 工作台展开“场景设置”，再检查关联缺失与模型不可用的人工回退。已有记录时切换情境需要确认重置。

可分别体验互联网入向、出向与 NAT ACL。**出向／NAT 已纳入 [CR-1／B2 需求基线](../../24-scope-expansion-and-prototype-review.md)**；不是已经实现或验证的正式能力。NAT ACL 与 SNAT／DNAT 转换条目分开，不会根据缺失关联编造映射。

## 相比旧版改了什么

- 五个独立工作区、清楚的左侧导航、页面主动作与可读状态。
- 事实／候选／确认分层；确认使用结构化预览，不再用大块 JSON 充当主要交互。
- 发现列表与证据详情分开，报告使用可读版面，复杂说明按需展开。
- 统一排版、间距、颜色和控件；桌面、平板和窄屏有不同布局。
- 保留确认失效保护、旧版本冻结、单任务执行、取消保留结果、部分完成与本地处理状态。
