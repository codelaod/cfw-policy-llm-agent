          1. 工作台载入人工样例，查看资产与边界。
          2. 资产页区分事实、候选与确认。可以保留未知。
          3. 审计页选择单一边界，显式启动、推进或取消模拟。
          4. 发现页核对证据，把建议加入本地待办或暂缓。
          5. 报告页保留旧版本，资料改变后准备新一轮复审。
          无云／模型调用、无服务端或浏览器持久化。出向与 NAT 需求已确认；页面仍是人工示例，接入、规则与正式设计尚未验收。后续正式前端不会直接把这份 HTML 当组件系统。
