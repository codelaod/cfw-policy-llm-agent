# E0 本机依赖与契约执行记录

日期：2026-10-28。用户在承接对话明确同意开始E0；本轮只用人工数据、显式假凭据和本机HTTP端点。需求B2／设计v0.6不变，没有真实云／模型请求，没有暂存、提交或推送。

**结果：E0最小工程、固定依赖和关键契约路线成立，可进入E1人工案例离线闭环。** 当前不包含正式规则、业务确认、审阅、报告或受限Agent业务链。机器可读的实际汇总见 [e0-local.json](e0-local.json)，完整验收要求仍见[验证计划](../verification-plan.md)。

## 实际工程与环境

- [server](../../../server/README.md)：独立Go module，Gin、GORM／libtnb纯Go SQLite，显式SQL迁移、三任务槽位、人工任务／持久事件；独立实验模块保持原状。
- [web](../../../web/README.md)：Vue／TS／Vite／Router／Nuxt UI／Tailwind，只有`/e0`联调台；应用口令仅页面内存，请求头鉴权fetch SSE和JSON轮询。
- [API产物](../../api/README.md)：实际Swag生成JSON／YAML，另存实现的E0事件子集schema。
- 本机工具运行时：Debian 13、Linux／WSL2 x86-64，Go 1.26.10、Node 24.22.0、npm 11.19.1；16逻辑CPU、可见内存15868MiB，无额外cgroup CPU／内存配额。**没有按2CPU／4GiB档位限制，本轮不是性能验收，也不报告P95／容量达标。**

固定后端直接依赖包括Gin v1.11.0、GORM v1.31.2、libtnb/sqlite v1.2.2（modernc v1.56.0）、Eino v0.9.22／openai组件v0.1.13；CFW SDK固定已核读提交对应`v11.1.1-0.20261009173233-c44859c166b7`。完整依赖以go.mod／go.sum为准。

前端固定Vue 3.5.44、Router 4.6.4、Nuxt UI 4.12.0、Tailwind 4.3.3、Vite 8.3.5、TypeScript 5.9.3、vue-tsc 3.3.13和eventsource-parser 4.1.3；本地图标固定lucide 1.2.147。完整依赖以package.json／package-lock.json为准。

## 运行结果

| 验证 | 实际操作与结果 | 限定 |
| --- | --- | --- |
| 无CGO构建与存储 | `CGO_ENABLED=0`构建／测试；真实文件WAL、8连接普通共享池，持有4条不同物理连接逐一验证外键与5秒busy timeout；JSON、false／空集合、事务回滚均通过 | 未实现完整业务表；无写队列、读写分池或checkpoint调度 |
| 状态与事件原子性 | 人工触发事件INSERT失败，状态／seq随事务回滚；重开可查，迟到成功不能改中断／取消终态 | 没有以日志或内存事件假装保存成功 |
| 三会话 | 三个HTTP请求全部到达本机屏障才放行；第4个排队，任一槽位释放后继续；8路并发同键只创建一个任务，同会话新任务409 | 证明人工HTTP重叠，不证明真实云／模型吞吐 |
| 取消与隔离 | queued立即取消且零HTTP；运行取消一个任务不影响其他会话，事件与任务ID不串用 | 正式消息／scope／报告隔离待实现 |
| SSE与轮询 | 实际网络flush与ResponseController写截止入口有效；断开后仍完成，读取持久尾部不增加调用；分页／422游标／终态204通过 | 未实测120秒轮换、15秒心跳长期行为、慢客户端和生产反向代理 |
| 应用保护 | 缺口令在打开库前拒启；头鉴权、Host／Origin、未知API JSON404通过；Gin异常恢复不输出请求头 | 本机单操作者；非公网认证方案，运行时口令轮换未实现 |
| 重启与备份 | 实际第二服务进程被锁拒绝；重开中断遗留人工任务，不重放HTTP；关闭库后复制并在独立目录恢复通过 | E0 queued也标中断；正式queued期限／预算恢复留E2，业务原文尚不存在 |
| SDK／模型控制点 | 固定Eino实际非流式Chat Completions本机请求；CFW WithContext及模拟凭据交换能取消物理HTTP；交换1次＋SDK内部重试2次共用预记上限3，后续被拒；解码前限额、错误正文替换、拒重定向／非loopback通过 | helper仅在测试存在；内存次数不是正式持久账本，模拟交换不是官方STS续期验收 |
| Swag | v1.16.6从实际注释／DTO生成JSON／YAML；再次生成逐字节相同；Gin实际路由与规范双向对账通过 | 只有已实现的E0接口，无业务API占位或公开Swagger UI |
