## 实际范围

- [领域与输入](../../../server/internal/domain/audit.go)：固定分区、控制面／IPv4子域、来源、采集／构造与评估时点、快照／画像／业务／规则／语义版本。普通上传强制`imported`，不能自称真实观测或改变已采用基线。
- [规则内核](../../../server/internal/audit/kernel.go)：IPv4 TCP／UDP、区间划分、三值首匹配、顺序／状态／引用／默认行为，50,000单元分配前上限与有界取消；CHK-01～08、OUT-01／02、NAT-01／02。M1仍关闭。
- [人工制品](../../../testdata/public/README.md)：入向、有限出向、NAT出向三份固定构造；与内置构造逐项一致，所有地址／角色／授权／保护／关联都是案例设定。
- [离线应用](../../../server/internal/app/audit_service.go)与[持久层](../../../server/internal/storage/business.go)：输入→规则→保存发现／证据→审阅→JSON／Markdown公开导出；重开后可查。原始规则不被审阅或后续调用方修改。
- [公开投影](../../../server/internal/report/report.go)：固定文案与报告内别名，不导出原IP、资源标识、字段路径、用户／模型自由文本或例外理由。重复维护候选以策略引用呈现，不虚构地址或零端口。
- [复审](../../../server/internal/recheck/recheck.go)：固定输入之间比较、关系持久化。缺对象／检查／覆盖或范围／业务／语义条件变化时不可比较；只使用“本次未再检出”，不称真实已修复。

当前E1的业务接口仍是Go应用服务；HTTP／五视图、持续会话和确认表单在E2接入，不能用E0诊断页面冒充业务Web验收。

## TDD及实际结果

最终运行`CGO_ENABLED=0 go test -mod=readonly ./... -count=1`：**84个顶层测试，含子项196项通过，失败0**。其中审计33、应用8、复审7、报告14、存储8个顶层测试；另外保留协议探针7、HTTP7的既有回归。80个固定种子小全集交叉验证是内核正确性测试，不是80个人工评价案例。

```bash
bash scripts/e0.sh test
cd server
CGO_ENABLED=0 go test ./internal/audit ./internal/app ./internal/storage ./internal/report ./internal/recheck -count=1
```

测试使用真实文件SQLite、WAL普通共享池、短事务及实际重开。E1新增了显式业务DDL；既有库须先按[后端说明](../../../server/README.md)运行明确迁移，正常启动拒绝缺少业务schema的旧库，不自动迁移。

| Review中实际发现的问题 | 先红→修复→复验 |
| --- | --- |
| 路径合并跨越业务上界后漏算集合差 | 按真实业务边界再拆分，保留精确剩余；独立穷举交叉测试 |
| 未导出区间字段序列化导致重复配置误判 | 比较真实规范区间与匹配／生效／动作条件；禁用条目仍可作维护候选 |
| 多条未知／重复必要访问生成相同结果ID | 同检查同实际查询聚合、保留全部缺口与证据；实际Run→SaveAudit唯一约束通过 |
| 私网／共享／测试等特殊来源误报公网，未知分类被当安全 | 固定IANA表，最长前缀True例外，未知分类保留；CHK-07／08限定明确公共单播配置域，其他业务集合不自动过滤 |
| 集合差忽略取消 | 原40,200单元例取消50ms后仍运行约7.18s；预解析去重并分批检查context，修复后同例约54～57ms返回，保留已证明部分；不是性能SLA |
| 报告声称不存在的审阅版本 | 核对历史revision与plan，允许真实旧捕获版本；同键回放仍优先 |
| 证据字段／对象／服务或来源保证伪造可保存 | 验证真实JSON Pointer、选择范围／策略／服务、采集时点、枚举及来源basis／必需假设 |
| 计算或SQLite等锁期间取消丢结果 | 计算停止后有限本地保存使用服务context；保留结果并返回取消，不冒充任务完整成功 |
| 审阅中途失败留下半记录 | 注入action插入及head更新失败，历史／head／幂等整笔回滚，同键可重试 |
| 公共报告与规则的重复候选枚举不一致 | 用真实三边界Run产物做跨包回归；JSON／Markdown维护候选不生成虚构流量 |

补充回归保留：缺白名单仍可有独立CHK-07；未知不是缺失；角色不替代授权；数据库用实际服务端口；NAT关联不足不推路径；原报告字节不随新意见变化；同键同内容先回原审阅，新键旧修订才冲突。

最终独立Review核对上述修复、定向复验规则／持久链，未发现阻止E1阶段提交的新实质问题。正式业务HTTP／Web异常矩阵和模型工具链仍需各自阶段验证。
