## 实际运行的限定路径

- 正式Go／SQLite：空白会话→候选／消歧→版本化计划→原子接受→规则→固定报告。多个ID、跨地域、更换目标、模式、原请求重放及旧计划失效有针对性回归。
- 同一已接受audit：签名SDK→loopback HTTP→共享物理账本→目录观察→两轮采集→一次晚封存→规则／报告，没有子collect或新预算。明确ID合格复用保持原时点，新增云／模型尝试为0；强刷不复用，模型不可用保留规则及部分报告。
- 原接受计划不改写；执行视图由持久binding及sealed输入派生。接受时业务head／水位及纳秒比较，阻止较晚确认进入旧任务。宽快照按明确受理身份投影子集，保留整分区ACL、引用与原窗口。
- 目录观察保留完整／截断／未知／失败及已见候选，raw仅私有列。NAT目录只表示CFW管理子域；名称核原生／防火墙两字段，网关ID与地域保持配对。
- 结构化metadata／SG进入固定工具，保留方向、动作、协议、范围、顺序及未知条件；完整空集／partial／not_collected分开。ID、名称、标签和地址按任务别名投影，角色候选仍需可定位已返回证据与人工确认。
- workload贯通preview／accept／worker／规则／模型／持久／双格式报告。45秒规则窗口、7轮模型逻辑请求＋6次工具到保存导出、51资产、1101策略、大于50000单元与更严小值／0均有定向回归或独立实际复现。7轮使用人工Eino模型，不能当7次真实HTTP。输入关系验证子context不向实际计算借额度。
- 3会话准备同时推进、第四排队、同会话第二任务拒绝已运行；loopback尝试与同一共享账本一致。取消不虚构sealed输入，已观察目录可读；事件补发不增加请求。
- 固定历史本地解释不新建任务；模型解释另接受零云计划。人工变更后的强刷生成新审计并关联旧报告，旧结论不改写。这不等一次真实人工整改。
- 显式env-file承接七字段，进程存在含空值优先，JSON互斥、状态分层；已绑定application-root授权可继续用，无绑定不造额度。模型名、512和更严私限保留。授权修订保留attempt，新Ref不得重置累计。
