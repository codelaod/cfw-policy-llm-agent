# D5-04 WHATWG SSE 线格式与 EventSource

来源：https://html.spec.whatwg.org/multipage/server-sent-events.html

核对日期：2026-10-27

类型：项目自写核读摘要；不是官方全文、依赖构建或集成结果。

规范定义 text/event-stream、UTF-8、event/data/id/retry、空行分派、注释及重连。EventSource 构造参数没有通用自定义鉴权请求头选项；本项目选择 fetch 响应流沿用应用访问头，不能期待 fetch 自动实现 EventSource 的恢复行为。帧可能跨网络 chunk，注释心跳不成为业务事件。项目 seq 与幂等、补发存储另行定义。
