# D4-01 HTTP 条件请求与业务修订契约

来源：https://www.rfc-editor.org/rfc/rfc9110.html

核对日期：2026-10-27

类型：项目自写摘要；不是 API 实现或互操作测试。

RFC 9110 第 13.1.1 节定义 If-Match 条件请求语义，条件不满足时不应执行所请求的方法，通常以 412 表示失败；规范还规定了确认重复成功等例外处理。它不能与应用自行定义的业务修订字段混用。本项目 v0.4 首版选择 JSON expected_revision 类字段加事务 CAS，动作冲突用 409；并未实现 HTTP ETag／If-Match 功能。后续如采用标准条件头，需按该规范单独设计和验证。
