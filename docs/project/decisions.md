## 4. 文档维护原则

当前项目采用按职责分类的一份正文，不再新增“第N轮review”作为主入口。修订结论直接落实到对应需求／设计；跨文档的阶段结果只更新此决策页，待执行事项列入实施或验证计划，实际结果保存在证据区。

本轮目录治理合并了重复G2审核包、设计增补和自审过程；接口／并发内容进入正式设计，DFX进入验证计划；论文修订记录压缩为一份维护说明。旧过程统一由Git追溯，不将review重新堆入archive，也不额外保存批准文档副本。
