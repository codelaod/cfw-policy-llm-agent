# Go + Eino 离线集成验证记录

日期：2026-10-21。状态：本地模拟集成验证已运行；真实模型与云接口未验证。

## 1. 本轮范围与依赖

用户同意优先验证 Go + Eino，并要求参考资料随 Git 保存。实现放在独立的 [实验 module](../experiments/eino-offline/README.md)，不创建正式后端、前端或完整审计规则引擎。

| 项目 | 实际记录 |
| --- | --- |
| 环境 | Linux/WSL，Go 1.26.10 linux/amd64 |
| module 语言级别 | `go.mod` 为 Go 1.24.0；未逐一实测其他 Go 版本 |
| Agent 框架 | Eino v0.9.22，Go module 依赖与校验和已固定 |
| 模型 | 本地确定性 `fixtureModel`，没有实际大模型调用 |
| 数据 | 人工构造资产与管理来源，来源明确标记为 synthetic |
| 网络 | 首次准备下载依赖；测试/运行禁用模块代理与远程校验查询，不使用模型或云服务 |
| 缓存 | `.cache/go-mod`、`.cache/go-build`，均忽略；未修改全局 Go 配置 |
| 不需要 | Node、数据库、Redis、Docker、云 SDK、模型密钥或阿里云凭据 |

参考资料完整性校验另使用现有 Python 3.13.5 标准库；脚本要求 Python 3.9+，不安装 Python 包。Go `-race` 检查使用当前环境已有的 C 工具链，不是普通运行前提。

## 3. 两条脚本路径

| 人工样例 | 脚本模型调用 | 工具调用/结果回传 | 输出 |
| --- | --- | --- | --- |
| 已给定管理来源 | 3 次 | 查询资产，再查询业务意图；2 次结果回传并核对调用 ID | 有条件建议，保留规则顺序/默认行为前提 |
| 缺少管理白名单 | 2 次 | 仅查询业务意图；1 次结果回传 | 待确认，不编造白名单 |

上述次数是测试驱动的回调次数，不是付费模型请求次数或 token 开销。路径和输出由测试脚本预设，只能说明 Eino 执行循环、工具结果回传和自有校验层可运行，不能证明真实模型能自主选择工具或推荐更准确。

## 4. 覆盖的拒绝与失败行为

- 未注册工具不执行；工具访问当前任务以外的资产被拒绝。
- 非法 JSON、未知字段与多余 JSON 数据被拒绝。
- 工具失败保留失败事件，不标成成功。
- 最终输出非 JSON、缺少前提、编造证据或修改给定来源被拒绝。
- 缺少白名单时不能输出具体访问来源。
- 框架迭代上限、模型/工具调用上限、工具和最终结果字节上限。
- 取消与超时产生失败终态，已有事件仍可定位。

本轮初次适配曾因只实现 `WithTools`、未读取模型运行选项中的工具定义而失败；根据固定版本源码修正后，正向路径与反例通过。反例增加预期错误原因检查，避免因为同一个初始化错误而产生“全部拒绝所以测试通过”的假象。

## 5. 能支持的选型结论

在当前环境中，Go + Eino 可以承载本项目所需的小型工具循环，并与自有权限、证据和输出校验层组合。当前没有发现必须因本地执行器不可用而切换 Python 的阻碍。

这只是继续评估 Go 路线的依据，不是正式选型验收；尤其不能据此宣布兼容所有 OpenAI 兼容服务。

## 6. 后续真实验证需要什么

- 真实模型：服务地址、接口形态、模型标识、服务端/本地私有凭据，以及确认的调用预算；验证多轮调用、输出、流式、错误与用量。
- 真实云 API：另行授权账号、产品版本、地域与最小只读权限，验证实际字段、分页、保护状态及资产关联。
- 真实模型的上下文与证据输入需继续按公平实验条件固定，不把脚本样例结果当论文实验结论。

以上均未在本轮执行。不得把密钥写到 Git、聊天公开记录或示例报告中；不能用当前脚本替代真实服务测试。

## 7. 模型配置入口补充

已增加根目录 `.env.local`（私有且忽略）、`.env.example`（空白模板）与 `config-check` 入口。它只读取、校验并输出脱敏摘要，不初始化模型 Provider；测试中本机 HTTP 服务的请求计数保持为零。真实服务和凭据有效性仍未验证。

配置检查结果不显示实际地址、模型名或密钥；错误不拼接原始值。环境变量只在读取时覆盖文件，不修改进程或全局环境。离线样例保持不读取私有模型配置，见 [使用说明](../experiments/eino-offline/README.md)。
