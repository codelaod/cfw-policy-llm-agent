## 3. 优先讨论的近期候选

### F1：近期防火墙策略异常分析

BRINGHENTI D, BUSSA S, SISTO R, et al. Atomizing Firewall Policies for Anomaly Analysis and Resolution[J]. IEEE Transactions on Dependable and Secure Computing, 2025, 22(3): 2308-2325. DOI: 10.1109/TDSC.2024.3495230.

- 来源：[作者机构库](https://iris.polito.it/handle/11583/2994408)；[机构库正式发表版 PDF](https://iris.polito.it/retrieve/61c4a0e3-1eab-4b58-9f80-6f5b8119bb75/Atomizing_Firewall_Policies_for_Anomaly_Analysis_and_Resolution_VOR.pdf)。

- 适合支撑：将规则匹配空间分解后开展异常分析，替代当前背景中主要依赖2005年研究的论据，并作为国外研究现状的直接相关工作。
- 引用边界：面向包过滤策略及论文定义的异常；不把其异常消解能力写成已经识别全部业务风险，也不据此承诺实现整套原子谓词算法或自动修改云配置。

- 来源：[作者机构库](https://iris.polito.it/handle/11583/2958744)；[机构库正式发表版 PDF 入口](https://iris.polito.it/retrieve/handle/11583/2958744/633f5cef-eb77-4947-b03a-dd71abb57327/Automated_Firewall_Configuration_in_Virtual_Networks.pdf)。

## 4. 背景与研究现状应怎样一起改

### 4.1 选题背景与意义

保留用户当前从临时端口开放、资产用途变化等运维问题切入的写法，不改回空泛的行业增长或厂商介绍。建议只重点联动两处：

1. 第2段将“已有研究建立规则异常分析方法”的主要论据调整为近期策略分析研究，按实际方法重写，不直接沿用旧文献对应句子。
2. 智能体引入段保留ReAct、Toolformer与工具安全的不同作用；补充近期网络配置分析已有LLM与工具结合的实践，再说明本题拟做的工程闭环，而不是由通用Agent研究直接跳到云防火墙。

可讨论的衔接写法（不直接替换用户正文）：

> 近期研究已从规则匹配空间分析、基于安全要求的配置求解，以及大模型辅助网络配置分析等方向探索自动化方法〔F1、F2、D3〕。围绕云防火墙日常审计，研究拟进一步结合只读配置采集、经确认的业务要求与证据补查，组织可审阅的推荐和整改后复审流程，并通过对照实验评价动态补查的作用与代价。

这段是拟研究工作的定位，不宣称其他研究均未考虑业务要求、解释或人工参与，也不宣称系统效果已经验证。

### 4.2 国内外研究现状

仍可保留现有国内／国外分节，但分节内部按问题组织，而非按年份或作者逐篇罗列：

| 部分 | 建议组织方式 | 主要文献角色 |
| --- | --- | --- |
| 国外：配置语义与策略分析 | 规则异常分析 → 给定要求下的配置求解，说明各自的输入条件与输出 | F1、F2；不再将F2写成AWS可达性分析 |
| 国外：工具增强与安全任务 | 保留执行流程、工具学习训练、安全任务和间接提示注入的差别 | 当前[2]、[3]、[4]、[6] |
| 国内：配置验证与策略分析 | 先说明网络验证脉络，再结合近期实际工具和策略分析研究 | D1、现有[11] AT4FP、D2 |
| 国内：智能体与网络运维 | 通用工具／Agent综述提供概念，D3作为直接相关研究重点比较，根因分析仅作邻近场景 | 当前[12]—[15]及D3，最终按篇幅取舍 |

初步比较后的写作建议：本题应以云防火墙业务中的工程设计与验证为重心，不将方法组合本身包装为首创。拟突出配置事实与业务确认分离、信息不足显式处理、受限证据补查、条件化推荐与人工复审，以及相同条件下的协同效果评价。这是本文选择的侧重点，不是关于已有研究均未覆盖这些内容的全面检索结论。

### 4.3 研究现状评述与相关技术正文

- 评述从“各类方法解决什么、依赖哪些输入、与本项目对象有什么不同”落到研究问题，避免先写不存在相关研究再安排系统。
- 当前策略语义正文引用[9]；如果正式删除这篇，技术正文、阅读指南和题录须一起调整，不能只改背景和综述。
- 不为追求新年份声称用过原子谓词、形式化求解器或知识图谱。论文借鉴的方法、实际采用的方法和待验证方案分别说明。
- 第六章三组对照仍服务现有研究问题，不借新文献扩大成网络形式化验证性能竞赛，也不引用别人的准确率作为自己的效果。
