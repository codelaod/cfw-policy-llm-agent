# 论文开题与文献

本目录维护论文材料，不作为系统审批或研发任务的第二入口；当前系统基线见[项目决策](../project/decisions.md)。

| 文档 | 职责 |
| --- | --- |
| [开题报告](开题报告.md) | 唯一Markdown正文：背景、综述、技术、需求、方法、七章提纲与正式参考文献 |
| [文献阅读指南](文献核验与阅读指南.md) | 15篇来源、阅读重点、核验深度与引用边界 |
| [结构化题录](references.json) | 与正文编号一致的正式题录与来源 |
| [编写与核验说明](编写与核验说明.md) | 合并后的语言、结构、引文及维护约定；不再按轮次堆自审和候选讨论 |

正文、题录和指南联动维护；项目进度、批准、Git和执行证据分别归项目／验证区。正文采用正式学术表达，业务确认与信息不足作为功能流程写清，不把“待验证”项目提醒混入正文。学校模板／个人信息按实际要求另行补充，不伪称最终文稿或学校验收已通过。

不维护Word／PDF副本；根忽略规则继续防止本地排版导出误入Git。
