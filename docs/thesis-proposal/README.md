# 论文开题报告与文献资料

本目录保存论文开题报告的Markdown源稿、文献题录及审阅记录，与项目需求和系统设计文档相互引用。以Markdown为仓库中的阅读和修改入口。

## 阅读入口

- [开题报告](开题报告.md)：论文题目、背景与意义、国内外综述、相关技术、系统需求、研究内容与方法、组织结构、论文提纲、参考文献和写作进度。
- [文献核验与阅读指南](文献核验与阅读指南.md)：15篇论文的原始入口、阅读重点与引用边界，以及技术核对用的官方资料；不并入提交版开题报告。
- [参考文献结构化题录](references.json)：与正文编号一致的文本题录，包含来源、国内外分类、语种与核对日期。
- [提纲与近五年文献调整记录](提纲与近五年文献调整讨论.md)：2026-10-26 的前轮讨论与本轮处理结果；第1—5节保留替换前编号，第6节记录当前正式文献及正文联动修订。
- [自审记录](自审记录.md)：发现、修订理由、设计一致性、引用和文稿校验记录；不并入提交版开题报告。

## 文稿约定

- 开题报告正文采用正式学术表述，直接说明研究对象、方法、系统需求、评价方案和写作安排。项目进度、审核状态、核验深度、修改提醒与阅读限制分别放在决策记录、自审记录和阅读指南，不混入提交正文。
- 系统中的业务确认、信息补充和异常处理写成明确的功能与流程，不用“待确认”“未验证”“后续观察”等项目记录口吻代替技术说明；研究计划与已有成果分开表述。
- 论文题目：《基于大模型智能体的云防火墙策略审计与推荐系统设计与实现》。个人信息按要求跳过。
- 研究围绕公有云云防火墙的策略审计与推荐展开。阿里云是首版接口适配与演示验证平台，选择时考虑资源成本控制；在接入需求与实验环境中说明，不将其写成论文面向的特定厂商，也不宣称已支持多云。
- 正式参考文献共15篇，国内9篇、国外6篇；对应9篇中文论文与6篇英文论文。本轮已替换6篇较早文献，并同步背景、国内外研究现状、评述及受影响的技术引用；正式发表年份为2023—2026年，较早网络首发时间与实际核验深度另列，不宣称全部全文已精读。
- 论文提纲调整为七章：第二章为“系统相关技术分析说明”，第五章为“系统实现”，第六章为“系统测试”，第七章为“总结”；两级标题为主，核心实现与测试最多细化至三级。需求、技术和评价说明以项目现有文档为依据，不将论文文稿审核等同于系统设计批准或业务验收。
- SQLite沿用纯Go驱动约束、短事务、单数据库连接且暂不启用WAL；云平台保持只读，策略由人应用后复审。
- 写作与开发同步推进，进度采用相对周次，具体日期按学校安排填写。

## 文稿格式与维护

以`开题报告.md`作为唯一正文源稿，文献题录和阅读指南随正文同步维护，不维护Word／PDF副本。旧的本地排版副本已清理，原始模板不修改、不随本目录发布。正文按Markdown章节名定位，不依赖导出文件或页码；仓库根目录`.gitignore`保留排版导出的忽略规则，防止生成文件误入版本管理。
