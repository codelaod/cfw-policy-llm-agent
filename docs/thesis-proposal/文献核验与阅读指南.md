本文件仅作阅读辅助，不并入提交版开题报告。题录、可访问摘要和正文关键段落的核对深度逐篇标注，不声称15篇全文均已精读、下载或复现实验。六篇较早文献已从本版正式题录移除；此前讨论与旧编号保留在[调整记录](提纲与近五年文献调整讨论.md)，该记录中的替换前编号不用于当前正文。

## 建议阅读顺序

1. **审计对象与策略语义**：[8]网络验证分类 → [9]AT4FP → [1]匹配空间与异常分析 → [10]流量辅助策略分析，注意不同输入与任务的区别。
2. **与本题直接相关的大模型网络应用**：优先读[4]配置分析，再读[14]SDN配置生成，比较输入、工具、输出和评价对象，不把模型与工具的组合本身当成首创。
3. **智能体构建与工具使用**：[11]构建综述 → [12]工具学习进展 → [13]工具使用综述 → [2]ReAct；[3]Toolformer只用于理解工具学习训练路线。
4. **工具安全边界**：[5]间接提示注入，转化为外部内容隔离、对象授权和参数校验的测试问题，不照搬攻击成功率。
5. **按需比较**：[6]给定安全要求下的配置求解、[7]渗透测试、[15]根因分析，仅借鉴相应建模或流程与评价组织，不扩展为本项目必须实现的任务。

核心领域、方法来源和邻近场景分开使用：配置分析主要参考[1]、[8]—[10]，直接相关的大模型网络应用为[4]、[14]，智能体方法参考[2]、[3]、[11]—[13]，安全边界参考[5]；[6]、[7]、[15]不直接证明本系统的审计效果。
