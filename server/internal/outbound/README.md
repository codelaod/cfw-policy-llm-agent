# 物理请求与用量记录

Manager为已接受任务绑定固定来源和只读路由。每次真实HTTP（含身份、有限SDK重试）先持久记录，再发送；保存状态、耗时、HTTP状态与受控错误。模型usage从原始响应读取，缺失保持未知，不能使用SDK默认零代替。

`AttemptUsage`按任务或会话汇总实际请求、已知token与未知用量；溢出时标明未知总量，逐次记录保留。查询不设旧106条截断。历史累计量不参与准入，没有预算名称、额度表、owner绑定或增额修订。

发送仍校验任务活动、截止时间、取消、配置版本和允许效果。固定来源／路由、无代理、拒绝重定向和响应大小保护继续生效；不能用模型或资源描述改变权限。记录失败停止后续发送，避免无法追踪的调用。事务不跨网络等待。

配置检查和Manager构造零外呼；本目录人工HTTP回归不证明真实云或模型质量。启动与数据库说明见[后端](../../README.md)。
