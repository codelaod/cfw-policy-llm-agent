# 离线审计 Web 工作区

正式入口为 `/overview`。五个业务视图使用服务端持久记录：数据与任务、资产与业务确认、审计过程、发现与审阅、报告与复审。`/e0` 保留为隐藏的人工事件契约诊断页。

## 本地运行

版本基线：Node **24.22.0**、npm **11.19.1**。直接依赖固定精确版本，传递依赖由 `package-lock.json` 固定。

```bash
cd web
npm ci
npm run dev
```

Vite 仅监听 `127.0.0.1:5173`，将 `/api` 代理至 `http://127.0.0.1:8080`。先按服务端说明启动后端，再在浏览器打开 `http://127.0.0.1:5173/`，输入本机服务的应用访问口令。没有新增 Node 业务服务或 Nuxt 服务端。

```bash
npm test
npm run build
```

`build` 先运行严格类型检查再生成 `dist/`。`npm run preview` 仅预览静态构建，不代理 API；完整操作可使用开发代理，或按[后端说明](../server/README.md)用`--web-dir ../web/dist`开启单Go服务同源托管。构建产物和依赖目录不进入 Git。

## 当前操作链路

- 载入互联网入向、有限出向或 NAT 人工案例，或导入最大 5 MiB 的规范化 JSON。来源、资料时点与完整性声明始终保留；导入不会升级为真实只读观测。
- 在资产页创建服务端草稿，分开编辑角色、完整允许上界、服务允许／必要访问及有期限的业务例外。先保存并预览差异，再明确选择确认部分；新增服务访问要求不会自动勾选角色确认。
- 审计页预览固定资料、范围和调用效果，明确接受计划后创建任务。已有规则事实先展示；模型未配置时保留规则结果并标记阶段边界。
- 发现页分开展示原始判定、固定输入证据值、严重程度、整改顺序及本地审阅历史。采纳为待办或暂缓不会改写规则判定，也不表示已修复。
- 报告页生成新的固定 JSON／Markdown 版本，通过带访问头的请求下载。使用新资料复审时沿用原评估条件并创建独立计划，再明确接受启动，旧报告保留。新资料缺旧对象时显示409 `RECHECK_NOT_COMPARABLE`／`object_missing`；已保存比较从任务结果的`recheck`读取，不把不可比较或“本次未再检出”称为真实已修复。
- 会话抽屉恢复服务器保存的当前会话与公开消息，明确区分用户、应用记录和模型消息；发送提问才使用模型通道。未配置模型时保留编辑，不伪造助手回复。

## 恢复与失败边界

应用访问口令仅保留在页面内存，通过 `X-App-Token` 请求头发送，不进入 URL、构建环境、localStorage 或 sessionStorage。锁定和刷新后需要重新解锁。当前会话指针保存在服务端，不按最近更新时间猜测。

确认、拒绝、任务启动、审阅和报告创建在未知失败时保留原对象、请求正文和幂等标识，等待人工核对或同一请求重试，不后台重放。服务端明确拒绝的请求允许重新编辑。未保存编辑只在当前页面会话中暂存；页面关闭或刷新不会把内存编辑冒称为持久草稿。

正式任务使用 `/api/v1/jobs`；E0 诊断继续使用 `/api/v1/e0/jobs`。fetch SSE 与轮询沿用同一连续 `seq`，只恢复观察，不重建、不取消任务、不重置预算；取消必须明确操作。事件必须提交后可读，支持规则结果、公开消息、报告和终态引用。页面离开时关闭观察，重开历史从服务端恢复。

事件回归覆盖 UTF-8 分片、CRLF、多条 data、连续游标、鉴权中断、轮询补齐和 partial 终态。单事件 UTF-8 正文上限 4 KiB，解析缓冲采用保守字符预算；超时与取消由局部 AbortController 管理。

当前为本机离线链路，正式API不读取云／模型凭据或向真实云／模型外呼；真实Agent、采集和外部预算准入仍按后续阶段实现。构建／状态回归不等于真实云接入、正式模型效果、所有目标浏览器兼容或正式评价通过；实际浏览器和服务端联调结果由项目验证区记录。页面使用系统中文字体和本地 SVG／随包图标，无 CDN 字体或图片，Markdown 使用文本渲染。

## 固定依赖来源

2026-10-28 从官方 npm registry 核对并锁定：Vue 3.5.44、Vue Router 4.6.4、Nuxt UI 4.12.0、Tailwind CSS 4.3.3、Vite 8.3.5、TypeScript 5.9.3、vue-tsc 3.3.13、eventsource-parser 4.1.3。

E0 首次构建发现 vue-tsc 3.3.13 无法调用 TypeScript 7.0.2 的 `typescript/lib/tsc` 导出入口（`ERR_PACKAGE_PATH_NOT_EXPORTED`），因此固定兼容的 TypeScript 5.9.3，不以移动 latest 作为工程版本。

- [Nuxt UI Vue/Vite 安装与配置](https://ui.nuxt.com/docs/getting-started/installation/vue)
- [eventsource-parser 源码与解析器说明](https://github.com/rexxars/eventsource-parser)
- [项目事件详细设计](../docs/design/frontend-and-events.md)

选定 Nuxt UI 的 Node 要求为 `^20.19.0 || >=22.12.0`，eventsource-parser 要求 `>=22.12`；本工程按上述 Node 24 基线验证。现代浏览器构建目标沿用 Chrome 111／Safari 16.4／Firefox 128，实际浏览器实测版本另记，不声称覆盖所有目标浏览器。
