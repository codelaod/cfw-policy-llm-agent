# 审计 Web 工作区

正式入口为 `/conversations`。目标、澄清、候选选择与执行提议通过服务端持久接口保存；没有快照也能先表达目标。五个辅助视图使用服务端持久记录：数据与任务、资产与业务确认、审计过程、发现与审阅、报告与复审。`/e0` 保留为隐藏的人工事件契约诊断页。

## 本地运行

版本基线：Node **24.22.0**、npm **11.19.1**。直接依赖固定精确版本，传递依赖由 `package-lock.json` 固定。

```bash
cd web
npm ci
npm run dev
```

Vite 仅监听 `127.0.0.1:5173`，将 `/api` 代理至 `http://127.0.0.1:8080`。先按服务端说明启动后端，再在浏览器打开 `http://127.0.0.1:5173/`，输入本机服务的应用访问口令。没有新增 Node 业务服务或 Nuxt 服务端。

```bash
npm test
npm run build
```

[对话浏览器检查函数](scripts/conversation-browser-check.js)用于专用的本机公开人工夹具服务：通过真实 Go API 保存目标、选择候选、接受计划、运行规则、导出固定报告及重开历史，并检查窄屏、会话隔离和敏感输入。它需要专用服务与明确的公开 fixture 元信息，不读取真实私配，不应对用户实际业务库运行。用既有 Playwright CLI 打开该服务后，将整段函数交给 `run-code`；测试口令从忽略的公开 fixture 文件取得而不回显。结果／截图位于忽略的 `output/playwright/`，不将该联调解释为真实云或上游模型验收。

`build` 先运行严格类型检查再生成 `dist/`。`npm run preview` 仅预览静态构建，不代理 API；完整操作可使用开发代理，或按[后端说明](../server/README.md)用`--web-dir ../web/dist`开启单Go服务同源托管。构建产物和依赖目录不进入 Git。

## 当前操作链路

- 对话为首入口：新建未绑定快照的会话，发送名称／ID／地域／类型等目标，由服务端解析、检索与给出澄清；浏览器不运行人工原型状态机、不本地决定资源或生成成功答复。目录未知、未穷尽、同名及资料不足按服务端状态呈现，不显示伪安全结论。
- 候选选择提交规范身份及目标版本；计划展示对象、资料策略、规则／模型模式、云读取与模型效果、缺口和限制，再明确接受。默认只运行规则；已配置模型不等于本次授权。模式或固定资料变化后，先保存新选项并重新核对；blocked 或没有可执行计划的提议不能启动。
- 当前目标与历史任务分开展示。任务卡只读取该任务的持久状态、事件和结果；先显示规则、再等模型，支持显式取消和恢复观察。资料准备记录独立显示本任务返回的候选、目录来源／时点、各有限查询完整性、未核实筛选与受控失败状态。可信有限空集与未知／缺页／失败分别呈现；候选只用明确云 ID 预填新目标，旧 accepted 提议和任务保持原版本。
- 对话和五个辅助视图共用服务端版本化 GuidanceCatalog，通过带访问头的本地 GET 读取。普通引导只预填，打开动作先核对会话、目标修订、任务、报告和固定资料／草稿归属，再进入现有页面；不会替用户新建计划、发起任务、取消或确认业务要求。缺少有效关联记录时显示缺项，晚响应不会跨会话覆盖或导航。
- 载入互联网入向、有限出向或 NAT 人工案例，或导入最大 5 MiB 的规范化 JSON。来源、资料时点与完整性声明始终保留；导入不会升级为真实只读观测。
- 在“数据与任务”读取服务端显式云连接的本地目录，明确选择有限范围、资产或 NAT 网关策略集，以及同范围未归档会话。连接目录不核对身份或访问云；不在浏览器填写凭据、端点或接口动作，空资产列表不会扩大为扫描账号。
- 云读取先预览强制刷新计划，展示共享额度内的云／凭据物理 HTTP 上限和模型上限 0，再明确接受。仅身份核对保存为部分结果并标明 `IDENTITY_ONLY`，不生成产品资料；产品采集分别保存两轮观测、分页完整性、语义摘要与局限。身份已核对不代表产品权限、字段、完整性或真实云能力验收通过。
- 资料视图中的独立采集任务完成后不改变当前资料、不自动确认业务资料或启动审计。任务页可明确选择返回的固定资料，进入人工业务确认或审计计划预览；审计仍需另外接受，原任务结果与确认版本保留。
- 在资产页创建服务端草稿，分开编辑角色、完整允许上界、服务允许／必要访问及有期限的业务例外。先保存并预览差异，再明确选择确认部分；新增服务访问要求不会自动勾选角色确认。
- 审计页预览固定资料、范围和调用效果，明确接受计划后创建任务。已有规则事实先展示；模型未配置时保留规则结果并标记阶段边界。
- 对话归属卡按已选择规范身份预览／确认组名、成员与授权来源；普通标签不产生可信归属。超过单批保留完整集合并预览串行父计划；任务卡和过程页显示各段独立输入／报告、实际覆盖／失败／未处理，父请求没有合并审计结论。
- 发现页分开展示原始判定、固定输入证据值、严重程度、整改顺序及本地审阅历史。采纳为待办或暂缓不会改写规则判定，也不表示已修复。
- 报告页生成新的固定 JSON／Markdown 版本，通过带访问头的请求下载。使用新资料复审时沿用原评估条件并创建独立计划，再明确接受启动，旧报告保留。新资料缺旧对象时显示409 `RECHECK_NOT_COMPARABLE`／`object_missing`；已保存比较从任务结果的`recheck`读取，不把不可比较或“本次未再检出”称为真实已修复。
- 对话主入口恢复服务器保存的当前会话、目标与公开消息，明确区分用户、应用记录和模型消息。规划、状态与受限请求先由服务端保存和反馈；只有明确受理的执行效果才进入任务观察，不把每条消息都当成模型调用。模型未配置仍可保存目标、人工确认和规则检查，不伪造模型回复。
- E3任务结果已接入，任务页独立展示模型解释、待确认角色、四类条件建议、人工下一步及本次绑定的证据别名；角色候选可在同一业务草稿卡接受、修改、拒绝或保留未知，辅助表单使用同一草稿和分项预览。展开证据只读本任务封存输入／规则结果，不使用当前资料或其他任务别名替代。
- 逻辑模型／工具次数与账本中的物理 HTTP 尝试分开。`reported_tokens: null` 保持未知，部分未报告或溢出明确标注；不把 SDK 默认零值或次数当作完整 token 用量／费用。旧接口缺少新字段时仍按未知展示。

## 恢复与失败边界

应用访问口令仅保留在页面内存，通过 `X-App-Token` 请求头发送，不进入 URL、构建环境、localStorage 或 sessionStorage。锁定和刷新后需要重新解锁。当前会话指针保存在服务端，不按最近更新时间猜测。已识别凭据在发送前移除，服务端敏感内容拒绝也会清除原文与待提交正文；不宣称能识别任意秘密。

目标发送、候选选择、计划接受、确认、拒绝、任务启动、审阅和报告创建在未知失败时保留原对象、请求正文和幂等标识，等待人工核对或同一请求重试，不后台重放。服务端明确拒绝的请求允许重新编辑。主对话的未知提交与编辑按会话在当前工作区内存暂存，切换辅助路由不会丢失原请求标识。已保存的消息与目标恢复以服务端为准；未保存编辑只在当前页面会话中暂存；页面关闭或刷新不会把内存编辑冒称为持久草稿。

正式任务使用 `/api/v1/jobs`；E0 诊断继续使用 `/api/v1/e0/jobs`。fetch SSE 与轮询沿用同一连续 `seq`，只恢复观察，不重建、不取消任务、不重置预算；取消必须明确操作。事件必须提交后可读，支持规则结果、公开消息、报告和终态引用；`cloud_result_saved` 阶段提交后重新读取与本任务绑定的云结果。页面离开时关闭观察，重开历史从服务端恢复。云任务启动结果未知时仍保留原计划及幂等标识，显式重试核对同一次启动。

事件回归覆盖 UTF-8 分片、CRLF、多条 data、连续游标、鉴权中断、轮询补齐和 partial 终态。单事件 UTF-8 正文上限 4 KiB，解析缓冲采用保守字符预算；超时与取消由局部 AbortController 管理。

当前已接正式有界Eino Agent、固定资料工具、结果持久化与共享物理HTTP账本。默认无模型配置可运行离线规则；模型仅由服务端显式私有配置注入，浏览器不接收模型凭据。启动／预览零外呼，接受计划或明确发送才可能在授权预算内调用。公开报告的Agent层使用固定模板／公共别名；受保护任务结果可见完整经校验解释，原规则保持独立。当前E3验证中的模型均为in-memory或loopback人工脚本协议fixture，不证明上游MiniMax真实兼容、自主选择质量、真实云、20～30正式案例、真实整改或2 CPU／4 GiB标准性能通过；最终浏览器与服务端联调结果见[E3记录](../docs/validation/evidence/e3-local.md)。页面使用系统中文字体和本地 SVG／随包图标，无 CDN 字体或图片，Markdown 使用文本渲染。

E4 Web 当前通过本机阿里云协议人工夹具联调：身份核对、入向采集、NAT 网关策略集采集及单独接受的仅规则审计，共 15 次本机云／凭据 HTTP、0 次模型 HTTP。界面的只读观测来源标记表示经过受控采集链路，人工响应仍不是用户账号的真实云观测；SDK／传输／两轮采集／SQLite／SSE 成功也不替代真实身份、产品权限、默认语义或整改验收。范围与证据见[E4记录](../docs/validation/evidence/e4-adapters-local.md)；本机浏览器结果保存为忽略产物 `output/playwright/e4-browser-checks.json`、`e4-event-schema.json` 和 `e4-*.png`。自动回归覆盖精确有限选择、身份与产品结果区分、跨任务引用拒绝、会话修订／来源切换的晚响应隔离及原计划幂等重试。

2026-10-30当前代码窗口已完成整体Review修复：审计页预览／接受迟到回执按任务、会话和资料隔离；报告复审接受卡明确显示固定对象／资料、继承模式及云／模型效果。Web193项、类型检查与生产构建通过，当前结果与仍待验的完整旅程见[现行阶段证据](../docs/validation/evidence/conversation-implementation-local.md)，E3／E4数字各自保留为历史窗口。
